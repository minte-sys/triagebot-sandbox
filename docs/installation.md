# Installation

## Requirements
You need Python 3.11 or newer and git.

## Windows
Open PowerShell, create a virtual environment with py -3.11 -m venv .venv,
activate it with .venv\Scripts\Activate.ps1 and run pip install -e .

## Linux and macOS
Create a virtual environment with python3 -m venv .venv, activate it with
source .venv/bin/activate and run pip install -e .

## Upgrading
Pull the latest code with git pull and run pip install -e . again.
